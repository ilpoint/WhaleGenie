# WhaleGenie 使用说明

这份说明写给用这个程序的人，用中文说明程序怎么用：宏包是什么形状，拾取器与落点怎么用，每一步能交回
什么，运行与调试怎么看，画面从哪来、怎么取，以及程序自己的文件放在哪儿。要改这个仓库，看 [dev.md](dev.md)；
复测见[这里](dev/delivery.md#性能测量)。

主窗口标题栏的太阳 / 月亮按钮在浅色与深色之间切换，选择记在 `settings.json`。设置页的「主题」还多一档「自定义」：选它以后挑一个强调色，改完立即作用到所有打开的窗口；控件底子可以另选深色或浅色。自定义只剩强调色一项——实心按钮、选中行和强调文字都由它推出来，推不到足够对比度（白字要 ≥ 4.5:1，强调文字对窗口底要 ≥ 4.5:1）的颜色会被拒绝并改用内置强调色，窗口上会写明。强调色和主题选择都记在同一个 `settings.json`；旧版本存下的 22 项配色只保留强调色那一项。

**第一次打开、手上什么都没有的时候**：主列表空着，下面那枚「新建宏」就是入口。帮助菜单的「快速上手」打开
的是随程序装好的这份手册（包里的 `doc/manual.md`），找不到那一份时才打开仓库里的页面。

新建宏时会先填好 `Macro 1` 这样的默认名，编号取项目里已有 `Macro N` 的最大编号再加一；中英文界面都用 `Macro`。宏名就是调用名：不能空，也不能和项目里别的宏重名。名字框下面会直接写出原因，问题解决前「保存」是灰的。

重名只可能从外面进来，这时不报错、也不丢东西，而是给**后进来的那个**名字加上日期：导入一个包，里面有本项目已经有的宏名，那个宏会变成
「整理 (2026-10-26)」；一个手改过的包文件里本来就有两个同名宏，后读到的那一个同样加上日期（同一天再撞就再加编号）。
先有的那个保留原名，因为文件里的调用与触发器都是按那个名字写的。改名之后，这个宏自己的触发器与菜单项跟着换成新名字，所以还能用。
导入进来的宏保留它自己的**分组**名，那是宏的一部分；**轮盘槽位不跟着导入**——轮盘属于项目，导入的只是宏。
要让它上轮盘，在「轮盘」页里放到一格即可。
