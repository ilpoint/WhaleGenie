# 拾取器

所属：[WhaleGenie 使用说明](../manual.md)。

## 拾取器

编辑动作时，需要"屏幕上的某个东西"的参数都有对应的拾取按钮，不用手写坐标、路径或标题：

| 参数 | 按钮 | 做什么 |
| --- | --- | --- |
| 目标图片（`vision.findImage` / `waitImage` / `clickImage`） | 加一张 / 浏览… / 截屏… / 删除 | **一列图，一行一张**，从上往下试，第一张认出来的就是这一步用的那张（同一个按钮换了字、图标另一个尺寸，写一行就行）；每行可以从磁盘选图，也可以在屏幕上拖一个矩形当场存成 PNG，行首显示缩略图。要的不是第一张时，用「高级设置」里的「认哪一张」 |
| 单个图片（`clipboard.writeImage`） | 浏览… / 截屏… / 清除 | 选磁盘上已有的图片，或在屏幕上拖一个矩形当场存成 PNG；字段下面显示缩略图。图片也可以写成前面步骤存下的图片变量，框里打进几个字符就会把那些名字列出来 |
| 窗口（`window.*`、`vision.captureWindow`、`uia.*`、看屏幕的步骤、后台输入、窗口触发器） | 选择窗口 | 下拉里有六种走法：前台窗口（不指定）、沿用上一次用的窗口、本宏已经用过的窗口、此刻打开着的窗口（点一条就取走，不必按 F1）、捕获窗口、变量里的窗口。新建的一步若落点之上已经有人指定过窗口，默认就是「沿用上一次」：它不写死任何一个窗口，运行时取本次运行里上一个自己指定了窗口的步骤那句话，上面那一步换了窗口，这一串跟着换；一次都还没有过时它就是前台窗口。「取窗口」是到桌面上指一扇：按一下，鲸灵自己的窗口全部让开，指针移到哪扇窗口它就被框出来，**按 F1 确认**，Esc 取消。拾取期间**鼠标照常能用**：可以点别的窗口把它摆到前面、点任务栏启动一个应用、拖动窗口，框跟着指针走；左键既不取走也不拦，取走只由 F1 决定——与框选区域是同一套确认方式。框的是窗口本身，不是按"前台窗口"猜——按按钮的那一刻前台就是鲸灵自己，从前那颗「取当前窗口」因此永远取不到东西。也可以打开「捕获窗口（按 F1）」进"获取窗口"这一页从列表里挑：左边列着此刻开着的窗口，点一条就选它；右边是匹配方式、匹配内容与"现在会认到"（按这条规则此刻会认到哪些窗口），改一个字就看一次结果。取得的是一条窗口规则：`handle`、`title`、`process`、`class`、`how`、`caseSensitive`、`trim`、`multiline`，若写的是「沿用上一次」则只有 `follow: true` 一格；运行时按 `how` 选中的标题、进程名、窗口类或句柄重新查找。“窗口句柄（当前实例）”只认拾取到的那个窗口，适合同标题、同进程的双开；目标关闭后必须重新拾取，绝不回退到另一个实例。取得的窗口在同一个流程里可直接改匹配方式与比较开关，下面实时列出当前会认到的窗口，并在屏幕上框出命中的窗口；高亮框跟随目标窗口的层级，目标被遮挡或最小化时高亮也一起隐藏。按「使用这个窗口」才写回动作或触发器。窗口动作、看屏幕的步骤、`uia.*`、后台输入与窗口触发器都用这一条规则；后台输入只在输入方式为后台消息时读取它。窗口列表留空列出所有窗口，其它窗口动作留空取最前面的窗口。窗口坐标一律以客户区左上角为原点 |
| 位置（`vision.*`、`ocr.*`、按钮取坐标） | 拾取坐标 | 全屏定格画面；屏幕模式下十字线可走整块桌面，窗口模式下只在目标窗口客户区内显示十字线、UIA 描边和读数。读数框跟随指针，在同一个框里写明当前基准、窗口 X/Y、屏幕 X/Y、UIA 元素名称和「按 F1 获取窗口基准坐标 · Esc 取消 · 点击其他窗口不会结束拾取」。指针上方那枚**放大镜**把指针所指的一像素放大摆在正中，红框圈着它：整屏都是十字线时，一像素的差别只有放大才分得出来。指针移出客户区时隐藏十字线与窗口坐标，框内改说指针不在客户区，F1 不生效。UI Automation 只描边和补充元素名称，F1 取的仍是十字线所指的精确像素；目标窗口关闭时只允许 Esc 返回后重新获取窗口。**识别方式选窗口时，区域框选只允许落在目标客户区。** |
| 选择器（`uia.*`） | 拾取元素… | 鼠标移到控件上，蓝色边框圈出它，点击即写入选择器；它所在的窗口会顺手填进窗口过滤——填进去的是标题，所以「匹配方式」同时回到「标题包含」，拾取器读到的就是标题。**打开时鲸灵自己的窗口全部收起来**（含正在写宏的编辑器与问话的那个对话框），拾完按原状回来 |
| 页面里的元素（`browser.*` 的元素动作） | 在页面里拾取… | 在宏已经打开的那份浏览器上拾取；还没有打开时，按这一步的「网址」与「档案」开一份出来。点一下要用的元素：**最稳的那条说法**写进字段，其余的说法列在按钮旁边，点一下追成字段的下一行（见「浏览器」）。按 Esc 放弃 |
| 颜色 | 放大镜 | 取色器把打开那一刻的桌面拍成一张图铺满全屏，放大镜就浮在这张图上，方向键可逐像素微调；**打开时鲸灵自己的窗口全部收起来**，取完按原状回来。看到的就是取到的那一张图，后面的画面再动（网页被滚轮翻走、窗口自己刷新）也不会让颜色与画面对不上。取到的那一点**同时写进这一步的 X、Y**（这一步有位置字段时），瞄准哪个像素就取哪个像素的颜色，取完不必再对一次位置 |
| 屏幕区域（要读/要截的那一块、搜索区域、拖拽的起点终点） | 框选区域 | 在屏幕上拖一个矩形，一次填满整组参数；拖完还能接着调——在框里拖动移动它（指针是普通箭头），拖四角或四边的方块改大小，按 F1 确认、Esc 取消。读数提示跟着指针走。**按住拖动时**（画新框、拉四边、拉四角）指针右下方有一枚**放大镜**，十字线穿过指针那一格、红框圈住它，边线切在哪一格看得准；松手就收起来，只是把指针移过去瞄一眼时不出现。读数气泡挂在放大镜下面，两样都跟着指针但一上一下叠着，谁也不挡谁。拉过对边时矩形会**翻面**（而不是缩成一条线），框外超过几像素按下去就是**另画一个**，所以反着拉、挨着旧框拉都行。**框选期间鲸灵自己的窗口全部收起来**（含正在写宏的编辑器与问话的那个对话框），框完按原状回来；「截屏…」也用同一个框选器，在窗口还收着的时候按 F1 拍，拍之前先等桌面重画一遍，所以图片里不会出现它们。**要框的那块画面看得清**：窗口打不开一个洞，所以打开的一刻先把桌面拍成一张底图铺在里面，底图定格在那一刻——刚打开时屏幕上什么都还是原样（指针也是平时的样子），一拖出框才把框外压暗、框内照原样，拖动与改大小都在这张底图上对准。截图的那一块是四个数字字段（左上角 X、左上角 Y、向右的宽、向下的高），都在「基础设置」里，各自也可以写表达式；**四个数都留空就是整块屏幕**（少填一个，就从给出来的那条边一直量到屏幕边缘），截图参数表因此没有默认值，新建一步不会自己框住屏幕一角；识别文字的那一块是一张**列表**：一行一处，每一处要么是四个数字，要么是一个变量说出的整块矩形（截图留下的图片变量、装着 `left,top,width,height` 的矩形、一条带矩形的记录都行），**一处都不写就是整块屏幕**，写了几处就把每一处读到的文字按顺序接起来；****要读要截的那一块另有一格「矩形」收一条记录**：填上它，这四个数不参与，整块矩形由那一格给出——上一步的命中、一个窗口、之前截下的画面都带着 `left`、`top`、`width`、`height`，下一步就在刚找到的那一块上读或截（见「返回值」的记录一节）；**框选之后那一格会被清空**，刚在屏幕上拖出来的数就是你这一块。搜索区域一行一处，**四个数字压在同一行**（格子上写 X、Y、宽、高，长说明在提示里，框里右端那枚「取值」片写算式或变量）；截图的那一块也一样——一个矩形的四个数是一句话，从前两两一行、每格底下各带一段说明，四个数占掉一整屏；识别文字用的就是这张列表本身：行末「删除」去掉一处，下面是「加一条区域」，另有一格可以改由一个变量说明看哪里（截图动作留下的图片变量就在那张图里找，装着 `left,top,width,height` 的变量按它写的位置看，一条带矩形的记录也按它说的那一块看；这四个数与返回值里的 `left`、`top`、`width`、`height` 是同一组）。**拖拽的起点与终点各是两格数字**（起点 X、起点 Y、终点 X、终点 Y），每一端另有一格收一条记录（「起点」/「终点」）：填上就由那一格里的记录说出这一点（上一步的命中、一个窗口、一个元素都行，取的是那块矩形的中心），框选一次四格一起填：起点是矩形的左上角，终点是右下角。**写出来的数字从「识别方式」选定的基准量起，一条记录按屏幕像素读**（见「返回值」的记录一节） |
| 按键（`input.keyPress` / `keyDown` / `keyUp`） | 字段按钮 | 按键字段和组合键字段本身就是按钮，点开画着键盘的一页，点哪个键按钮就填入哪个键名（左右修饰键分开：左Ctrl 与 右Ctrl 是两个名字，和触发器绑定的一致）；PrintScreen、ScrollLock、Pause 在右侧导航键区最上面一行，F13–F24、媒体键、音量键、浏览器与程序键都在页面下方。字段旁边另有捕获按钮：按键字段是「设置按键」，点完按一下键盘上的键就填进去，按钮变成「请按一个键…」，填进去以后恢复；组合键字段是「设置组合键」，点完后依次按下组合里的每一个键，每按一次加一个键（要一起按住的键就一起按），按钮变成「停止捕获」，再点一次这个按钮或者按 Esc 结束。Esc 在按键字段里照常当一个键填进去 |
| 手柄控件（`gamepad.*`） | 虚拟手柄 | 弹出画着手柄的一页：按键点在键上，摇杆和扳机点在哪一根上就填哪一侧 |
| 变量（任何可以填变量的字段） | 取值（贴在字段里的那枚片） | 宏编辑器右上是当前文档的变量中心，可搜索，并按局部变量 / 全局变量 / 系统变量 / 步骤状态筛（另有「全部」一条）。双击的作用按变量种类分：局部变量与步骤返回名打开局部变量窗口，全局变量打开全局变量管理中心，形参与结果跳到宏接口，系统变量与步骤状态只读（双击没有反应）。变量多到放不下时，只有变量卡区域出现一条窄的上下滚动条，上方的搜索与分组留在原处；分组是五个短按钮，窄栏里也占一行。鼠标停在变量卡上会显示变量内容、类型、记录字段、来源、说明，以及哪几步读它；全局变量还会标出是否持久化。表头的「局部变量」「全局变量」分别打开两个管理窗，局部变量可以在那个窗口里新建。变量中心只用来查看：往里放值靠字段里那枚「取值」片，打开取值窗口后点一下变量——文字与整值字段直接写进光标处，写变量名的字段点一下选中、再按「确认」返回名字，点、矩形和窗口规则接收整条记录。记录写进普通标量字段时，只有一个同类型字段才自动写成 `field(记录, "字段名")`，多个候选项会弹出字段选择。每个能取值的字段都只有这一枚片，框外不再另排按钮。 |

看屏幕的动作（找图、找色、找文字、截图）旁边多一个「试找一下」：**只识别，不点击、不按键、
不写变量**，跑完弹出"识别结果"窗口 —— 截图作底，识别范围、全部候选、选中的那个、动作真正
要落的地方用四种颜色分开；右侧每一条命中都写出它落在哪儿、读到的是什么字、离这一步的门槛
还差多少（这一步没写门槛就不写这一句），都可以勾选显隐、悬浮联动、点一下拉到窗口中间。
**落在哪儿写的是矩形中心在前**（`(x, y)`，就是命中记录里那对 `x`、`y`，也是鼠标动作与拖拽两端从一条记录里取到的那个点），跟着是左上角与宽高：照界面上写的数填，不必自己把
宽高折半加上去。
找不到时不弹空窗，而是把最高分和它需要的门槛一起说明白。窗口一打开就按真实的画面区把整张图
铺满，**小图也放大**（参考图只有几十像素宽时留在原大就是窗口正中一枚邮票），窗口大小改了也跟着
重算（自己缩放过之后就不再跟着）。滚轮以指针所在处为中心缩放，按住左键拖动画面看没显示的那一半；
F11 把窗口铺满屏幕（Esc 退回），双击画面在像素原本大小与适应窗口之间切换；找图列了几张参考图时，
顶部写着"参考图 2/3"并显示认出来的那张。

右侧每一行分开两件事：上面一行是**位置**（中心在前，跟着左上角与宽高）；下面那个带「识别文字」
标题的下沉框里，才是这一步在那儿**读到的字**。两条都要看得清，因为一条是照界面上写的数填进
「X」「Y」的，另一条是要复制走的。勾选框决定这一条算不算数：图上画不画它、「复制」带不带它，
都看它；标题栏的「全选」「反选」一次改完（筛过的行不参与反选），「复制」把勾上的行按一行一条
放进剪贴板，右键某一行只复制那一行；下面的筛选框按文字或角色收窄列表。图上的字不画：字一多，
标签就把画面铺满了，而框里那段字才是要对着看的。从添加动作窗口开的那一份还多一枚「再看一次」：
只重新识别、不做动作，门槛改好按一下就在同一扇窗里看新结果；运行调试打开的那一份不给它，
那幅画面属于那一次运行。

「保存图片…」能把带框那张按原本大小存成 PNG，「保存原图…」存的是没有标记的那一张
（拿它剪新的参考图），两张都是原本大小。运行调试时每一步最后看到的画面也会
挂到它的步骤行上做缩略图（没有识别的步骤不显示），点开就是同一个窗口，跑完还能回看。运行时正在读哪个窗口也在屏幕上框出来，读到哪一步框就落在那个窗口上（这一步里把窗口拖到别处，框也跟过去），下一步开始或跑完就收。
