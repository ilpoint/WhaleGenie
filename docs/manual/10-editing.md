# 编辑宏

所属：[WhaleGenie 使用说明](../manual.md)。

## 打开编辑器

在「宏」页新建宏、双击宏卡片或点编辑按钮，会切到网页编辑器；标题栏「文件」菜单里的「编辑」和
原生菜单的编辑入口也打开同一页面。公共宏库在左侧「宏库」页管理；编辑器动作库的「公共宏」页会把
选中的公共宏复制成当前文档的子宏并留下一个调用步骤。

## 页面结构

编辑器是类 VS Code 的工作区：顶部是标题栏；左侧活动栏常驻，编辑器路由的侧栏换成 **动作库**；
中间是文档页签、工具条与步骤列表；右侧是 **变量中心与宏设置**；底部是状态条。

文档页签列出当前打开的父宏与子宏。切页签会保留各自的 C# 会话、撤销历史与未保存状态；页签上的
实心点表示未保存，警示图标表示宏还有保存前必须修正的问题。页签可关闭，关闭有未保存修改的文档会
先问「保存后再关闭」：确认保存成功才关闭，保存失败会保留页签并说明原因。末尾的「+」新建一个空白宏，
右端的导出按钮把当前文档写成一个独立包。

右侧栏上下两块同时在：上方是**变量中心**，列出当前宏能读到的变量，可按局部、全局、系统、
步骤状态过滤，也可以打开局部/全局变量对话框；下方是**宏设置**，再分「常规」（名称、描述、分组、
触发入口）与「专属设置」（输入限制、启停键、形参与返回值），保存与运行调试在它的底部。

工具条在文档页签下方：撤销、重做、编辑步骤、添加步骤、复制、删除、上移、下移，以及右侧栏的
收起/展开按钮。双击步骤行、点工具条的铅笔或按 F2 打开**动作编辑器**，步骤参数、条件、行表和
备注/超时/重试/失败处理都在那里；窗口较窄时右侧栏默认收起，工具条上的按钮可随时展开。

## 动作库

动作库在工作区第一列，按来源分四档：

- **基础动作**：左边一列分类栏（全部、键鼠、视觉、界面、浏览器、脚本、程序、数据、文件、剪贴、系统），
  右边是这一分类的动作卡片；卡片按小分组加标题。
- **流程控制**：重复、条件、多分支、尝试、跳转、等待等控制步骤，同样按小分组排列。
- **子宏**：当前宏自己的子宏；单击打开为独立文档页签。

搜索框按动作名、动作键、分类和说明过滤；搜索时不看当前来源，基础动作与流程控制合在一起找。
**单击动作卡片只是选中**；**双击卡片**、按工具条的「添加步骤」，或把卡片拖到步骤列表接缝，
先打开动作编辑器；确认后才把步骤加入列表。取消不改动列表。
每个步骤列表上方还有「添加」按钮，把当前选中的动作放进那个分节；多分支的「添加分支」会加一支新的
分支。动作库底部是「录制动作」：开始后捕获键鼠与手柄输入，再按一次停止并把结果写成步骤。

## 步骤

一步一行。行首的折叠钮只出现在块上；勾选框启用或停用该步骤（停用的行变淡并写「已停用」）；名称旁
的徽标分别是步骤 id、输入去向（前台/后台/驱动）和问题标记。行尾有上移、下移、复制、删除，选中行时
出现；选中后行下方展开完整摘要、备注与步骤设置摘要。单击选中，Ctrl/Shift 多选；右键菜单可以
编辑、启停、复制/剪切/粘贴、分组、提取为新宏、上下移与删除，行也可以拖到另一行前后换位。快捷键
与菜单一致：Ctrl+C/X/V/G/E、Del、F2、Ctrl+↑/↓、Ctrl+A 与 Esc。

块（重复、条件、多分支、尝试等）显示为一层卡片，下面的分节是它的步骤列表，缩进并带虚线。分节标题
右侧的「添加步骤」把动作库当前选中的动作放进该分节；多分支的「分支」分节用「添加分支」加一支，
「其他情况」是普通步骤列表。

步骤有问题时，列表上方会出现问题摘要；鼠标停在警示图标上可看具体原因。

## 步骤参数

动作编辑器先编辑一个未入树的草稿步骤：标题栏显示“添加动作”或“编辑动作”，下方按基础设置、
执行与容错、高级设置、其它设置分页；确认按钮是「添加步骤/保存步骤」，取消不改列表。

双击步骤行打开动作编辑器后显示：

- 参数按动作目录给的块分组，同一块里的字段相邻；成对的 x/y、宽/高压在同一行，矩形的四个数压成
  一行四格。不适用的字段不画，必填未填的字段标红。
- 文本、名字、颜色、多行、代码、窗口规则、元素选择器和条件单元格显示成框内的只读文字，框的右缘
  贴着一枚「取值」按钮；数字可以直接输入，按钮同样在框内。
  点「取值」打开取值窗口：上方是结构带，下面是运算符、变量和函数。点材料会插到光标处，点块上的叉
  可以摘除，点运算符可以更换，函数参数可以继续套函数；确认后把整条值写回这一格。
- 条件：按行编辑左侧值、比较方式、右侧值；可加行、加组，组有自己的连接方式（全部成立/任一成立/
  全部不成立），组可以嵌套。条件也可以直接写成表达式。
- 行表：搜索区域、图片列表、颜色点、颜色列表、按键序列和页面窄化各有自己的行表；每行可以加行、
  删行、拖动或按键写入。图片行显示缩略图和文件名，读不到时显示原因；区域行各有「框选区域」和取值
  按钮；颜色点行可以在取景图上一次点出多个偏移颜色。
- 返回值：基础设置末尾是每个动作声明的结果表，「留下 / 结果 / 结构 / 变量名」四列；勾选并命名
  的结果才写进步骤，重名时行下会提示并可以换一个名字。
- 记录形参：在「宏设置 → 专属设置」里声明记录字段，字段名和类型会出现在调用方的行表里；调用宏
  的实参也照被调宏的声明列在基础设置里。
- 全局声明：设置全局变量的步骤在基础设置里带一块声明，可改类型、默认值、说明和是否跨运行保留。
- 执行与容错：执行前/后延迟、超时、重试次数、重试间隔、退避方式（固定/每次翻倍/随机）、失败处理
  （停止、继续、下一轮循环、询问），并显示实际的重试计划；选「询问」时另有无人值守警告。
- 其它设置：步骤 ID（可复制）、是否启用和即将写出的 JSON 节点。

键位字段点「设置组合键」后直接按要用的键，也可以点旁边的键盘按钮在屏幕键盘上点选。键盘包含字母、
数字、导航块、小键盘、F1–F24、媒体键、浏览器键和应用键；组合键模式保持打开，按一次追加一段。
键位序列的每一行也有自己的键盘和捕获按钮。颜色、窗口、区域、点位、UIA 元素、浏览器页元素和图片
字段右侧都有对应的拾取按钮；窗口规则字段可以打开完整的匹配方式/内容对话框；取消拾取不改原值。
截图按钮把框选的画面存进当前宏的资源目录。文件路径字段的「浏览」按目录、读文件、写文件或多文件
打开系统对话框。

动作编辑器底部的「运行」按当前写法执行一次这一步：不可撤销的动作先确认，执行时鲸灵窗口让开，
看完屏幕的步骤会显示取景图和命中框。

宏设置「专属设置」页的录制区可以设置鼠标位置记录方式、鼠标移动/按键、键盘按键、手柄按钮、延迟、
忽略阈值和是否忽略程序发出的输入；「播放速度」按倍数缩放等待与节奏。录制按钮在动作库底部，
Ctrl+F10 开始或停止。

## 变量中心

右侧「变量中心」用五档过滤：全部、局部变量、全局变量、系统变量、步骤状态。变量片显示方便读的名字，
括号里是实际名字；持久化的全局变量另有徽标。鼠标停在变量片上，下方显示它的来源与说明。

顶部的「局部变量」和「全局变量」打开两个对话框：

- **局部变量**：声明这个宏自己每次运行开始时用的值；步骤写出来的名字也能在这里改名。改动随文档保存
  一起提交。
- **全局变量**：项目里所有宏共享的变量，可新建、改名、改类型/默认值/说明与持久化。改动先写进当前
  文档的草稿，保存文档后提交进工程。

## 宏设置

「常规」页编辑宏名称、说明与分组。名称不能为空，也不能与项目里别的宏重名；有问题时字段下方直接说明。
触发入口列表支持按键、定时、颜色、文件、程序、字串、空闲、窗口和窗口内接口；选中一条入口后编辑它的
字段，可启用/停用或删除。多分支、条件等动作不使用触发入口。

「专属设置」页编辑：

- **输入限制**：跟随程序的默认速率，或给这个宏指定每秒事件数；
- **启停键**：设置一个只属于这个宏的键；留空表示不设置；
- **形参与返回值**：名字、类型、必填、默认值与说明；记录类型还可以声明字段。声明不合法时保存会被
  C# 校验拦下，并在页面上说明原因。

子宏文档没有自己的触发入口和输入限制，这两块不会显示。

## 保存、关闭与快捷键

- 「保存」或 Ctrl+S 保存当前文档；保存按钮在右侧宏设置的底部，文档有未保存修改且能保存时可用。
- Ctrl+W 关闭当前页签；有未保存修改时先问保存。
- 非输入框聚焦时，Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤销与重做。
- 「运行调试」在右侧宏设置底部，会先保存当前文档，再进入运行与调试页；子宏与空宏不能直接运行。
- 关闭编辑器页签不会删除宏；宏列表里的删除仍走它自己的确认流程。

## 桌面交互

编辑器的步骤树、条件、变量、宏设置、触发入口与动作库都在网页。屏幕取色、框选区域、点位、UIA
元素和窗口捕获仍是原生覆盖层，由网页按钮打开；它们只做一次桌面操作，结果由 C# 写回同一个动作草稿，
不保存第二套编辑模型。窗口规则、菜单与运行调试页面在网页编辑，只有桌面让位与覆盖层留在 Avalonia。

## 子宏

父宏拥有的子宏显示在动作库的「子宏」页；单击打开独立文档页签。子宏页保存时写回父宏模型，父宏再
保存时一起落进工程。子宏没有自己的触发入口与输入限制。

## 公共宏库

左侧「宏库」页列出本机公共宏的名字、版本与说明。可以选择一个工程宏加入宏库，或用当前工程宏覆盖
已有条目；覆盖会按内容变化递增版本。删除只影响宏库，已复制进工程的副本照常运行。编辑器里只有文档页签的**导出**，
直接写当前文档；导入走「文件」菜单，导出宏走「宏」页卡片上的按钮，两者都由网页向导完成。
