# 编辑宏

所属：[WhaleGenie 使用说明](../manual.md)。

## 打开编辑器

在「宏」页新建宏、双击宏卡片或点编辑按钮，会切到网页编辑器；原生菜单里的「编辑」也打开同一页面。公共宏库在左侧「宏库」页管理，不再从编辑器里的原生管理窗口进入。

## 页面结构

编辑器沿用 VS Code 式外壳：左侧活动栏与页面列表，右侧是文档区。顶部页签列出当前打开的父宏与子宏文档，灰点表示未保存；页签旁可关闭文档，关闭有未保存修改的文档会先询问。打开多个文档时切换页签保留各自的 C# 会话、撤销历史和脏状态。

标题栏的「文件」菜单负责打开、保存、另存为、导入与全部关闭；「帮助」菜单放关于、版本和使用手册。

## 步骤

「步骤」区上方有动作搜索、动作选择和「添加步骤」：

- 搜索按动作名、动作键与分类过滤；选中一项后「添加步骤」放在根列表末尾。
- 选中接受子步骤的块时，可出现「添加到选中步骤内」，把新步骤放进块内。
- 每一步行首的勾选框启用/停用该步骤；行尾可上移、下移、复制、删除。
- 选中步骤后，右侧检查器显示动作参数。文本、数字、多行和条件字段旁有「插入取值」：下拉可快速插入变量，**构建取值**会打开可搜索变量与内置函数的对话框，拼好后写回字段。
- 键位字段可点「设置组合键」后直接按键捕获；图片字段可点「浏览」调用系统文件选择器；颜色字段可调用原生取色器。
- 记录类字段（如返回值行表）可加行并逐格编辑；块步骤的「添加步骤」和「添加到选中步骤内」共同维护嵌套树。
- 步骤检查器还可改备注、超时、重试次数、重试间隔和失败处理（停止、继续、下一轮循环、询问）。

## 条件

条件参数按行编辑：左侧值、比较方式、右侧值，行尾删除；行下方可加行或加组。组有自己的一组行和「全部成立 / 任一成立 / 全部不成立」连接方式，组可以嵌套；删除组会连同其子行一起移除。嵌套条件下仍可直接输入变量名和表达式，保存时由 C# 模型写成引擎读取的条件树。

## 宏设置与触发

名称、分组、说明直接写在文档区顶部。宏设置区可改输入限制（跟随程序设置或指定每秒事件数）和启用/停用键。

触发入口列表支持按键、定时、颜色、文件、程序、字串、空闲、窗口和窗口内接口；每种入口有自己的字段，可启用/停用或删除。菜单入口仍是项目级运行菜单管理的原生面，不在网页编辑器里添加。

## 形参与返回值

宏可声明调用时需要的形参和可返回的结果：名字、类型、必填、默认值与说明；选择记录类型时还可声明字段名和字段类型。形参与返回值都可用上移/下移调整顺序。声明不合法时保存会被 C# 校验拦下。

## 变量

局部变量墙列出当前宏声明的局部变量与步骤写出的局部变量；声明项可改名、改类型、改初始值和说明。全局变量墙显示整个工程的全局变量：新增、改名、改类型/默认值/说明/持久化只写当前文档的草稿，点「保存」才提交进工程；关闭文档会丢弃未保存的全局改动。

## 子宏

父宏拥有的子宏显示在「子宏」区；点名字会打开独立文档页签。子宏页保存时写回父宏模型，父宏再保存时一起落进工程。子宏没有自己的触发入口。

## 公共宏库

左侧「宏库」页列出本机公共宏的名字、版本与说明。可以选择一个工程宏加入宏库，或用当前工程宏覆盖已有条目；覆盖会按内容变化递增版本。删除只影响宏库，已复制进工程的副本照常运行。

## 保存、关闭与快捷键

「保存」和 Ctrl+S 保存当前文档；有未保存内容时页签带点，关闭会先询问。Ctrl+W 关闭当前文档；非输入框聚焦时 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤销与重做。关闭编辑器页签不会删除宏，宏列表里的删除仍走它的确认流程。

## 桌面交互

编辑、步骤树、条件、变量、公共宏库都已迁入网页。屏幕取色、图片选择、窗口拾取和运行调试中的部分桌面交互仍由原生窗口承担；它们只做单次桌面操作，不保存第二套编辑模型。
