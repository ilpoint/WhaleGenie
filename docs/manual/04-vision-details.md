# 图片识别与颜色细节

所属：[WhaleGenie 使用说明](../manual.md)。

## 图片识别与颜色细节

找图（`vision.findImage` / `waitImage` / `clickImage`）的**识别算法**是一枚下拉，四选一，
默认归一化相关：**归一化相关**先抵消画面整体明暗再比对；**相关**不抵消明暗，参考图很小时
更稳；**逐像素**要求两处几乎一样，纯色图标或对话框截图用它；**特征比对**把两边明显的特征点
配对，画面缩放或有小改动也认得出，慢一些且只返回一个命中。选了特征比对，表单上就只剩它用得
上的那几项（最少特征对数、透明色、容差）—— 用不上的字段不会留在那里让人以为它起作用。
**参考图里不参与比对的那一块**叫「透明色」：填上那个颜色，它覆盖的像素就不参与比对。两件事都用
它——参考图里会变的那一块（按钮上的数字、会走动的进度条），以及图标自带的纯色底。后者常见得多：
从截图上裁下来的小图标总带着当时的底色，换一个底色就找不到了，掩掉底色之后同一个图标在哪都能认。
一格「透明色」用吸管在屏幕上取，也可以用表达式写 `#RRGGBB`、`RRGGBB` 或 `#RGB`；留空（默认）就是
整张图都参与比对，行为与从前完全一致。底色往往不是精确的一个数（截图上取色、轻微渐变），
旁边那格「容差 %」（0–100，默认 0）说一个像素偏离多少仍算作它，给到 5–10 更稳；这一档与找色族的
容差是同一个判据，「5%」在两处是一个意思。读不出来的颜色不会当成黑色掩掉，这一步报 `Run.BadPoint`。

列了几张参考图时，**认哪一张**（`imageSet`，在「高级设置」里）说清这一步要的是哪一张：
默认**认出的第一张**，就是同一个按钮有两套画法时的用法；**最像的那一张**把每一张都比一遍，
取分数最高的一张，用来在两张相像的图标里挑更像的一张；**每一张都要**要求这几张同时都在，
缺一张就当没找到，用于「整套都在才算到了这一步」的画面。交回命中时以列在第一张的那张为准，
「第几个命中」也在这张里数。颜色族的**命中排序**就是找色的**四向搜索顺序**，一共四种：**从左到右、从上到下**（默认）、
**从右到左、从上到下**、**从左到右、从下往上**、**从右到左、从下往上**。默认那种就是人读一页字的顺序；
另外三种从别的角开始数——一排贴着窗口右边或底边排的按钮，从那个角数第一个才是人眼里的第一个。
颜色的命中都是一像素，所以没有「面积最大」也没有「分数最高」；老宏里存着这些旧值（以及更早的
`readingUp` 等写法）仍按原来的说法跑，只是新写的步骤只在这四种里选。

点击图片、点击颜色、点击文字、点击检测到的物体都可以**把落点挪一挪**：「横向偏移」「纵向偏移」是相对命中框
中心的两个数，那个数不必自己量——按旁边的**「拾取点位…」**，它先按这一步现在的写法识别一次，
再把这一步要读的**整块地方**铺开：识别方式选屏幕就是整个桌面，选窗口就是那个窗口的客户区，
命中框画在上面。在图上点一下就是落点，点在命中框旁边、点在文字或图片之外都算数；
橙色圈标出偏移为 0 的地方，所以"往右下挪一点"是照着画面点，不是猜坐标。
整屏铺在一扇窗里很小时，滚轮放大、按住左键拖动画面，和看"这一步看到了什么"时一样。
这一步这次没找到东西时，它会直接说明，而不是开一张空图。

**多点找色**（`vision.findColors`）找的不是一个
颜色，而是**一个颜色加上它周围几个位置上该有的颜色**：一个红点只能说明"这里有个红东西"，
红点旁边还有什么才说明是哪一个红东西，两个长得像的按钮就是这么分开的。基准色是中间那个，
周围那些颜色各按**相对基准色的偏移**记录，每一个都要在写的位置上，整个图案还要落在搜索区域里面。
交回的位置是基准色那一像素，「试找一下」与识别结果窗口都能看到它把哪些点对过、各自要的是什么颜色。

**容差**之后是**「对比色」**这一节：**一处一行**，五格分别是**往右**、**往下**、**颜色**、
**不能是**和**容差**，行末是把这一处删掉的按钮；下面两枚按钮是**「再加一处」**与**「拾取偏移与颜色…」**。
放在颜色与容差之后，是因为那两格说的都是基准色本身，对比色是下一件事。
表格里直接键也可以，用拾取窗口在画面上点也可以：两者读写的是同一份，窗口里点完按「确定」，
表单上的行就跟着变。每一格都能写算式或变量（`12+3`、`$dx`），整块图案因此能跟着另一步
算出来的数一起挪。右边那枚色块是把写下的颜色画出来，十六进制数读不出对不对。

**颜色那一格可以写几个，用竖线分开**（`#E04A3F|#B03A33`）：同一个按钮按下前是一种红、按下后是另一种红，
它们是同一个位置，命中其中任意一个都算。这比放大容差稳，因为它说的是「就是这几种之一」，而不是「差不多红就行」。

**「不能是」**勾上，这一处就要求**不是**写下的那些颜色——用来写「这个角应该是空的」「图标这时不该在」。
勾上之后同一个位置仍然可以写几个颜色，意思是「这几个都不能是」。

**那一格容差是这一处自己的，留空就跟着上面「容差」那一格。** 这是多点找色最常调的旋钮：
基准色往往要严（0–2%），周围那些颜色会随光影、渐变偏，可以放到 10–20%。一个数同时管住两边，
不是太松（满屏误报）就是太严（稍微变个天气就找不到）。比如基准色 0%、周围某一处 8%，
就等于那一处每个通道允许偏约 20 级（满值 255）。

拾取窗口按下面这些规矩工作：

- 打开时先按这一步现在的写法识别一次，再把整屏（选窗口时是那个窗口）铺开，并带上这一步已有的那几处。
- 指针在画面上时旁边跟一枚**放大镜**：整屏缩进一扇窗后，一个像素只有零点几个点宽，偏移差一格是看不出来的。
- 在图上点一处即新增一条；同一条不写两遍，底色对不上的地方一眼就能看出来。
- 右侧一列就是这一步要写入的内容，每行带边框与序号，序号与图上的圆点一一对应；一处的颜色画成并排的小色块，
  「不能是」写作 `≠`，「单点容差」写作 `±N`，整行原文在提示里：

  - **拖圆点**：按住圆点拖到别处，该条随之移动，数字与颜色当场重算。
  - **右键圆点**：编辑、加备选色或删除该条；空白处按右键不做事，不会多出一条。
  - **滚轮键**：不再新增一处（以前按一下多一条，中键被当成拖动手势时容易多出来，已去掉）。
  - **按住 Shift 点一处**：给这一处**再加一种备选色**，位置不动——同一个按钮换一套配色画出来，
    那是「这一处可以是这几种之一」，不是两处。加到的就是点中的圆点那一条，没点中圆点时用到选中的那一行。
  - **右键 →「加备选色…」**：从屏幕上另取一种颜色加给这一处（这张图上没有的颜色只能这样加）。
    一处最多六种颜色，同一个颜色不会写第二遍。
  - **点一行**选中（再点一次、或点列表空白处取消），之后在图上点一处即移动该条。
  - **左上的「+」**：不点画面，直接键入偏移与颜色新增一条。

- 编辑或新增时，偏移 X、偏移 Y、颜色各占一行。这一窗是**手填一个点**，所以三格旁边没有取值片；
  算式或变量（`12+3`、`$dx`）仍然可以直接打进格子，提示里会列出能用的变量名。
- 按「确定」把窗里这一整张表写回这一步；按「取消」什么都不改。一处也没有时这一步无法保存，
  窗体下方会说明。

滚轮只负责缩放，画面靠左键拖动，与看"这一步看到了什么"时一致。

**查找颜色**（`vision.findColor`）看的是颜色在哪一点上，另有一个**至少占比**（`minCoverage`，
0–100，默认 0 即不看占比）看的是**这块区域里有多少是那个颜色**——血条涨到一半、按钮亮起来、
仪表过了刻度用后者，而不是找一个像素在哪儿。占比按整个搜索区域算，多行区域合起来算一个；
勾上返回值里的「占比 %」就能把它读出来。算占比要把整块区域走一遍，没问占比的步骤不会因此变慢。

查找颜色**在搜索区域里找**，不再接受点位：要看一个像素是不是某个颜色，用「比色」（`vision.matchColor`），
它没有搜索区域，只有一个点，交回 `matches`、实际颜色与偏差。包格式升到 22，旧包会被拒绝打开：
上一版里填了 `X`、`Y` 或「位置」的找色步骤，形状已经不同，重新录一遍比猜它原来想干什么可靠。
要一个像素的颜色本身用「取色」，要“等到它变成这个颜色”用「等到颜色」。

多点找色的对比色在包格式 **23** 里从一行文本改成了**一处一行**：旧包里那一行是
`12,-4,#FF0000; 0,3,#00FF00` 这样的写法，新包里是每一行三格。23 的包同样拒绝旧包，
按这一节重录一遍即可。

截屏存下来的图片放在**这个宏包专属的工作目录**里（`%APPDATA%\WhaleGenie\projects\<宏包名>-<路径哈希>\assets`），
保存宏包时自动收进包里的 `assets/`；项目还没保存过时先放在系统「图片」文件夹下的 `WhaleGenie`。
这么放是因为项目还没有文件时，这些图还不属于任何一个项目，放在人看得见的地方比放进程序的数据目录更好找；
搬走或删掉它们都不影响已经保存过的包。没有「图片」文件夹的机器（服务器、被精简过的用户配置）退回
`%LOCALAPPDATA%\WhaleGenie\images`。
同一个包再来一次还是同一个目录，两个同名的包各有各的，不会互相覆盖。路径的解析与截图落盘都在
`WhaleGenie/Storage/ImageAssets.cs`。
