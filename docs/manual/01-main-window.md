# 主界面、视图与轮盘

所属：[WhaleGenie 使用说明](../manual.md)。

## 主界面与侧栏

打开程序直接落在**宏列表**：没有单独的欢迎页，工程信息不再重复占一页。左侧活动栏从上到下是
**宏**、**公共宏库**，底部固定着**系统开关**与**开关键**、**设置**。编辑器和运行调试不占主窗口的
导航，它们从宏列表的编辑/新建/运行按钮打开一个独立的**宏工作台**窗口。

系统开关在任何页面都能按：上面一个电源按钮，下面是当前系统开关键。组合键按 `+` 拆成从上到下的
几行（例如 `Ctrl`、`+`、`K`、`+`、`L`），单键只有一行；点开关键进设置页修改。标题栏的项目名后
括号写出“项目自动保存已开启”。工作台有自己的标题栏和“编辑器 / 运行调试”两个页签；主壳不再显示
编辑器状态条。

## 触发视图与列表

主界面搜索框上方是 `全部 / 按键 / 界面 / 字串 / 菜单 / 轮盘 / 事件` 七个**视图**。它们是筛选而不是归属：
一个宏可以同时带键盘、菜单和轮盘，就在这几页各出现一次，而 `全部` 是唯一的完整列表，也是默认打开的那一页。
搜索框左边是**分组**筛选：全部分组、某个分组、未分组。分组是第二层——视图说这个宏怎么开始，分组说它属于
你哪一块工作，两者同时生效。分组名写在宏设置的「分组」格子里，留空就是未分组；最后一个宏离开某个分组时，
这个分组也就从筛选里消失。
宏设置分两页，标题下面一排按钮切换。**常规**页先显示宏名称、描述与分组；「触发入口」使用纵向卡片列表，
点击卡片即切换正在编辑的入口，卡片内可以启用或删除该入口；窗口与窗口内接口的规则由卡片下面的
「选择窗口」打开窗口规则对话框设置，和动作字段用的是同一个对话框。「添加入口」菜单按类型创建入口，并允许创建多条
同类型入口；一条入口都没有的宏只出现在“全部”，不会被执行，但仍可被别的宏按名字调用。
**专属设置**页放这个宏自己的东西：**输入限制**、**启用/停用键**与**宏接口**（形参与返回值）。
**从哪个视图点添加，新宏就带那个视图的入口**：在「按键」「界面」「字串」里新建，编辑器先放好一条对应类型的
入口（按键那条还没绑键）；在「菜单」里新建，保存后直接落到菜单第一页的第一个空格；在「轮盘」里新建，保存后
落到内圈的第一个空位。从「全部」和「事件」新建则是空的——「事件」不是一种触发方式，要自己选。
按键入口默认是**按一次执行一次**；要「再按一次才停」得在入口卡片里自己选。「没有入口」不再是错误状态：
宏照常存在、可以被别的宏调用，只是不会被任何触发入口叫起来。
宏卡片区域单独纵向滚动，顶部七页视图、分组、搜索框与“新建宏”按钮保持固定。

卡片右侧的开关是**启用 / 停用**这一条宏：左上角的圆点与开关必须同时显示同一状态（圆点为品牌色是启用、灰色是停用），
停用的宏不会被触发器叫起来。卡片左侧的拖动手柄可以上下拖动排序，顺序会写进工程并在下次打开时保持；
拖过之后列表按项目顺序显示，不再套用「已启用的宏排在前面」的自动分组。
在宏编辑器的「专属设置」里还可以给它配一个**启用/停用键**：按一下停用、再按一下恢复，这个键不会被宏发出；
宏停用时它仍然有效，所以同一枚键能把宏按回来。
右键菜单里也有同一项，写得是**接下来会发生的事**（「启用」或「停用」），旁边依次是运行调试、编辑、导出与删除。

- `全部`：项目里的每个宏，有没有触发入口都在这里。
- `按键`：键盘、鼠标、手柄绑定。
- `界面`：用同一条窗口规则认目标窗口；完全相同的规则自动组成一组悬浮按钮，同一组可包含多个宏。
- `字串`：输入缩写后执行宏，支持常用热字串的结束键、大小写、词中触发、删除输入和舍弃结束键选项。
- `菜单`：明确加入项目菜单；菜单固定为 4 列、上下各 3 行，并可为不同的目标窗口配置下半区。
- `轮盘`：任一场景的任一位置用到了这个宏。轮盘的位置随项目保存，所以换台机器打开同一项目仍然在。
- `事件`：颜色/像素变化、定时、文件或文件夹变化、程序启动/退出、窗口出现/消失和机器空闲。

界面宏在窗口规则命中时显示，按钮不抢前台焦点；整组可以拖动，位置按目标客户区保存，拖到客户区外松手会
自动回到客户区内。落到一个目标窗口后，别的程序到前台时这组按钮仍留在原窗口内，直到目标窗口关闭或
最小化；再切回目标窗口时按钮组仍在原处，不用拖一下窗口才出现。若前台窗口本身也符合同一规则（例如同一
程序的另一个文档），按钮组跟着这个前台窗口走；没有选择窗口的规则跟随前台窗口。
这组按钮与目标窗口**同层**：盖住目标窗口的程序也会盖住它，它不会浮在焦点窗口之上。把手右侧有两个按钮，
一个把它**折叠**成顶部一条约 20 像素的窄条、再点展开（窄条下面的部分完全透明，点下去会落到下面的窗口），
一个在**竖排与横排**之间切换；形状在本次运行内保留，按组分开。
每个窗口规则
组各有一个显示/隐藏快捷键，快捷键写在界面宏设置里；系统停用或该组被隐藏时它不出现。系统停用后，界面组和
菜单呼出快捷键都不响应，系统总开关本身仍可用。默认选中“全部”，搜索只缩小当前视图。系统总开关默认是
`Home`，侧栏常驻显示；菜单呼出键与系统总开关都保存在本机设置中，可在设置里修改，不随项目或宏包变化。

字串宏只匹配键盘实际产生的字面字符，不读取输入法候选，所以不匹配中文输入法提交的文字。默认必须再按
一个结束键，命中后删除缩写并保留结束键，再运行宏一次。结束键用字符按钮点亮或关闭，默认是 `Space`、`Enter`、`Tab`、`-`、`(`、
`)`、`[`、`]`、`{`、`}`、`:`、`;`、`'`、`"`、`/`、`\`、`,`、`.`、`?`、`!`，也可以在字串入口的
「捕获自定义按键」里加入任意单字符键盘输入；空格、回车和 Tab 都按字符本身保存，项目文件只在 JSON 层使用标准转义。
字串最多 40 个字符。
编辑器里的字符字段本身就是虚拟键盘按钮；点开后只输入字面字符，提供完整 ASCII 字母、数字、标点和上档符号，以及空格、Tab、回车；
Shift 切换大小写和上档符号，预览里用 `␠`、`⇥`、`⏎` 显示空白字符。右下角的「确定」把输入写回入口，
标题栏关闭和 `Esc` 放弃本次输入。**鼠标左键或右键的点击会重置热字串
识别器**；重置后需要从头输入。切换前台窗口、方向键、`Home`、`End`、`PageUp`、`PageDown` 或 `Esc` 也会
清空尚未完成的输入缓存；缓存只在内存里，不写日志。

菜单在鼠标指针附近打开，纵向让中间分隔条中心尽量对齐鼠标指针，靠近屏幕边缘时限制在当前显示器工作区内；
横向空间不足时从指针右侧翻到左侧。顶部显示鲸鱼图标、
“鲸灵”和设置按钮，右侧是搜索、置顶和关闭按钮，标题栏可以拖动，每个格子为 80×80 像素。上半区是通用宏，
默认 1 页、最多 8 页；下半区按设置里的窗口规则顺序取第一个命中项，没有命中时使用默认布局。每条窗口规则
都可以有最多 8 个下区页。鼠标滚轮位于上区或下区时分别翻动该区的页，44 像素高的中间分隔条同时显示上下两组
页码点。普通运行时菜单不抢前台焦点，方向键只在有宏的格子间移动，`Enter` 运行当前格，`Esc` 或再次按呼出键
关闭；未置顶时点击菜单外也会自动关闭。置顶只在本次打开期间有效，置顶后点击其他窗口不会关闭菜单，其他程序
中的 `Esc` 也不会被菜单截走；关闭按钮或再次按呼出键仍会退出。

搜索输入框默认收起并预留固定高度，点击标题栏的搜索按钮只显示输入框并取得焦点，不改变菜单尺寸，避免来回
抖动。搜索覆盖所有通用页和当前窗口规则页；清空或离开搜索框后菜单恢复为不抢焦点状态并把前台还给原窗口。
点击菜单内其他位置或窗口失去激活时也会收起搜索框。搜索保留格子位置，匹配项正常显示、其余淡化；`Esc`
在搜索框有内容时先清空，空时收起搜索框，再按一次才关闭菜单。

菜单没有单独的编辑模式。空格始终有添加图标，点击选择宏；占用的格子左键运行，右键直接提供“编辑宏、更换宏、
更换图标、调试运行”四项。按住左键 400 毫秒后拖动格子，可在格子间移动或交换。悬浮时格子略微放大并高亮，
提示显示宏名与说明。分页圆点和新增按钮始终显示；从第 2 页起可用右键删除页码，两个区域的第一页都保留。

底栏左侧按当前前台程序的进程名精确添加或切换到该程序的下半区规则，右侧禁止该程序呼出菜单。禁止项会出现在
设置里的“窗口规则”列表，删除对应行即可恢复。图标选择器列出 `Lucide.Avalonia` 包内全部 Lucide 图标并显示
原名，使用搜索和分页浏览，每页最多显示 140 个；也可以选择 PNG/JPEG/BMP 图片或“不使用图标”。宽高相同的
图片铺满格子，其他图片等比适应。菜单允许一个键盘组合、鼠标中键或鼠标 4/5 侧键呼出；左键、右键和滚轮仍不允许。
快捷键字段支持字母、数字、`F1`–`F24`、方向键、编辑键、小键盘键和修饰键组合；例如小键盘减号会显示并保存为
`NumPadSubtract`。界面组和支持的全局快捷键都按同一套名称识别，无法识别的键会当场提示而不会保存。

## 轮盘菜单

轮盘把常用宏放在鼠标指针周围，用方向和距离来选，靠肌肉记忆盲操作。**按住呼出键并立即移动**
才会弹出，轮盘以按下时指针所在的位置为中心。呼出键的**按下与松开都由轮盘接管**，所以拖动时下层
窗口不会画出自己的选择框，松开也不会弹出它的右键菜单；**按下后不移动就松开仍是一次普通点击**，
程序会把这次点击原样补发回去，该键自己的菜单照常出现。轮盘窗口本身是鼠标穿透的透明层，松开之后
不会留下一个“按着没放”的键。菜单宏用**鼠标中键按下**呼出，两者不能设成同一个键。

轮盘默认有两圈可见扇区：内圈 8 格、外圈 8 格（可设为 16 格），还能打开**第三常驻圈**，容量
选 0、8、16 或 24 格；全空的外圈会自动隐藏，轮盘便缩到真正有动作的圈。正上方是第 1 格，
之后顺时针。指针落在可见扇区上，扇区高亮并有一根**从中心指向指针的实线**；在**中心圆**内，
中心显示「关闭」，松开、按 `Esc` 或点鼠标左键都只是取消。**扩展圈不画在屏幕上**：指针移出
轮盘后，提示线变成**虚线**并伸出可见圆盘，末端跟着指针，轮盘中心只显示该方向动作的**宏名字或
备注**，朝那个方向划一下再松开即可触发。鼠标停在一个动作上时按重复触发键
（默认 `F1`，可改）可以再跑一次，不用松开触发键。超时（默认 20000 毫秒）会自动取消。
**滚轮**在轮盘开着时切换动作来源：上滚只用全局、下滚只用当前程序、再滚一次回到叠加。

设置 →「轮盘菜单」页里，触发键是一个**固定下拉**：鼠标右键（默认）、鼠标中键、鼠标前进键、
鼠标后退键。只给这四个是因为手势要“按住再移动”，左键要用来拖东西，键盘键则要一直按住再移动
鼠标，不是同一种操作。选的键与菜单呼出键或系统热键相同时这一项会被拒绝，状态行会写明被谁占了；反过来录菜单呼出键或
系统热键时，也会拒绝已经被另一个占用的键。
「启用轮盘菜单」关掉后完全不拦截所选按键。「默认禁用，只在指定软件下唤出」打开后，只有前台窗口
命中了某个**程序场景**的规则时轮盘才会弹出；桌面和其他软件里这个键仍是一次普通按键，不会被吞掉。
打开这个开关却一个程序场景都没有时，状态行会直接说“现在哪里都不会弹出”，避免以为按键坏了。
其余选项是轮盘尺寸（150–600，默认 420）、文字大小、第三圈容量、版面（外圈 16 格、隐藏空外圈、
只显示图标、中心显示动作名）、超时、重复触发键、操作（屏幕边缘限制、指针移到中心、提示线、
扩展圈名字）与外观（跟随主题、扇区光泽、悬浮边框、弹出动效）。**预览轮盘**会在独立窗口里打开轮盘，用界面内的指针移动、悬停、松开查看
会运行什么；不经过全局钩子，系统总开关关着也能用，按 `Esc` 关闭。

设置 →「轮盘动作管理」页里，左侧是场景列表（全局 + 按窗口规则认出的程序场景），可新增、编辑
规则、删除、上下移动；右侧是环形编辑器：

- **左键点扇区**快速选一个宏。
- **右键点扇区**打开「编辑轮盘动作」，在里面设置宏、备注和图标；「清除该位置」把这一格完全清空。
  在程序场景里指向一个**继承自全局**的位置时，对话框会带着全局动作打开，保存后这个位置就变成该
  程序自己的覆盖。
- 设了图标的扇区会在文字上方显示图标；打开「有图标时只显示图标」后只画图标。

规则和菜单宏同款：**从上往下取第一条命中的前台窗口规则**；程序场景只覆盖自己填了动作的位置，
其余沿用全局；一次轮盘弹出后场景冻结，前台窗口变化不会改变正在瞄的轮盘。

轮盘的**选项**（呼出键、是否只在指定软件下唤出、尺寸、文字、版面、外观）存在
`%LOCALAPPDATA%\WhaleGenie\wheel-menu.json`，
属于这台机器；**槽位与场景规则随项目保存**，跟着 `.wgmacro` 一起走，换台机器打开同一项目还是同一批
动作。旧版把规则也写在这个文件里，那一份不再读取。它不改 `settings.json` 和菜单呼出键。**系统总
开关没启用时，轮盘与菜单呼出键都不响应**；先按 `Home` 或点主界面的开关。设置页的状态行会直接写出
这一点，并提供一键启用。
