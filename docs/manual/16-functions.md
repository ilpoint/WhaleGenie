# 表达式函数一览

所属：[WhaleGenie 使用说明](../manual.md)。

## 表达式函数一览

下表是表达式里可以直接用的全部内置函数，与取值窗口函数盘里列出的那一份相同，分组也相同。点一张卡片就把
这个函数的空调用放进结构带的光标处，光标落在括号内，接着往参数位里填。卡片上写着 `截取文本 (substring)`
这样的中文名与代码名，卡片颜色说的是它属于哪一组；鼠标停在卡片上弹出的气泡里写着这个函数的写法、参数
个数、一句说明，再往下每个参数一行。筛选框里写中文名、代码名或写法都能找到它。下表中间那一列就是同一个
签名在中文下的写法，最后一列说这个函数做什么。写法里 `[, ]` 之间的参数可以不写，`...` 表示可以接着
往下写更多个。函数名不分大小写。结构带里参数超过三个或一行放不下时，每个参数各占一行，行前写着这个
参数的中文名、第几个、必填还是可选。

### 文本

| 写法 | 中文写法 | 说明 |
| --- | --- | --- |
| `upper(text)` | 转大写(原文本) | 把值写成大写字母。 |
| `lower(text)` | 转小写(原文本) | 把值写成小写字母。 |
| `trim(text)` | 去两端空格(原文本) | 去掉两端的空格。 |
| `length(value)` | 取长度(值) | 一个值有多少个字符，或一个列表有多少项。 |
| `substring(text, start [, length])` | 截取文本(原文本, 起始位置 [, 截取长度]) | 取一部分文字，起点从 0 数起，不写长度就取到末尾。 |
| `replace(text, old, new)` | 替换文字(原文本, 旧文字, 新文字) | 把每一处旧文字换成新文字。 |
| `replaceRegex(text, pattern, replacement)` | 正则替换(原文本, 正则, 替换内容) | 按正则替换，替换里用 `$1`、`$2` 引用括号里抓到的那几段；正则前面写 `(?i)` 表示不区分大小写。 |
| `split(text, separator)` | 分割文本(原文本, 分隔符) | 按分隔符切成一个列表。 |
| `join(list, separator)` | 拼接列表(列表, 分隔符) | 把列表的每一项接成一段文字。 |
| `contains(value, needle)` | 包含(值, 查找内容) | 文字或列表里有没有这一段。 |
| `compare(value, comparison, needle [, caseSensitive, trim, multiline])` | 比较(值, 比较方式, 查找内容 [, 区分大小写, 去掉两端空格, 正则按行]) | 按文本五档或数字方式比较一个值。 |
| `startsWith(text, prefix)` | 判断开头(原文本, 开头的文字) | 文字是不是以这一段开头。 |
| `endsWith(text, suffix)` | 判断结尾(原文本, 结尾的文字) | 文字是不是以这一段结尾。 |
| `indexOf(value, needle)` | 查找位置(值, 查找内容) | 这一段在第几个字符上，找不到是 -1。 |
| `repeat(text, times)` | 重复文本(原文本, 重复次数) | 把同一段文字重复若干遍。 |
| `concat(value, ...)` | 合并文字(值, ...) | 把每一个参数接成一段文字。 |
| `format(template, ...)` | 按模板拼接(模板, ...) | 把模板里的 `{0}`、`{1}` 换成后面的参数。 |
| `match(text, pattern)` | 正则匹配(原文本, 正则) | 正则有没有匹配到这段文字。 |
| `extract(text, pattern)` | 正则提取(原文本, 正则) | 正则匹配到的第一段文字。 |

### 数字

| 写法 | 中文写法 | 说明 |
| --- | --- | --- |
| `abs(number)` | 取绝对值(数字) | 一个数离零有多远。 |
| `round(number [, digits])` | 四舍五入(数字 [, 小数位]) | 四舍五入到整数，或到指定位数的小数。 |
| `floor(number)` | 向下取整(数字) | 向下取整。 |
| `ceil(number)` | 向上取整(数字) | 向上取整。 |
| `sqrt(number)` | 求平方根(数字) | 平方根。 |
| `pow(number, power)` | 求乘方(数字, 次方) | 一个数的若干次方。 |
| `min(number, ...)` | 取最小(数字, ...) | 这些数里最小的一个。 |
| `max(number, ...)` | 取最大(数字, ...) | 这些数里最大的一个。 |
| `sum(list)` | 求和(列表) | 把一个列表里的数加起来。 |
| `random([min, max])` | 随机数([最小, 最大]) | 一个随机数；写了范围就是该范围内的整数。 |

### 列表

| 写法 | 中文写法 | 说明 |
| --- | --- | --- |
| `list(...values)` | 新建列表(...值) | 把这些参数做成一个列表。 |
| `count(list)` | 统计项数(列表) | 列表里有几项。 |
| `append(list, ...values)` | 追加项(列表, ...值) | 在末尾加上若干项之后的副本。 |
| `insertAt(list, index, value)` | 插入项(列表, 序号, 要插入的值) | 在某一位上插入一项之后的副本。 |
| `removeAt(list, index)` | 删除某项(列表, 序号) | 去掉某一位上那一项之后的副本。 |
| `get(list, index)` | 获取列表项(列表, 序号) | 某一位上的那一项。 |
| `first(list)` | 取第一项(列表) | 第一项。 |
| `last(list)` | 取最后一项(列表) | 最后一项。 |
| `sort(list)` | 升序排列(列表) | 从小到大排好的副本。 |
| `sortDesc(list)` | 降序排列(列表) | 从大到小排好的副本。 |
| `reverse(list)` | 反转顺序(列表) | 前后颠倒的副本。 |
| `unique(list)` | 去掉重复(列表) | 去掉重复项之后的副本。 |
| `slice(list, start [, length])` | 截取列表(列表, 起始位置 [, 截取长度]) | 取列表的一部分，起点从 0 数起，不写长度就取到末尾。 |
| `where(list, field, compare, value [, caseSensitive, trim])` | 筛选记录(列表, 字段名, 比较方式, 值 [, 区分大小写, 去掉两端空格]) | 按一个字段筛选记录；文本用五档比较，数字可用 >、>=、<、<=、=、!=，表格里读出的数字文本也按数字比；读不成数字或缺字段的行会跳过并写进运行日志。 |
| `column(list, field)` | 取一列(列表, 字段名) | 取出每条记录里同一个字段的值，组成一个列表；缺字段的行会跳过并写进运行日志。 |

### 日期

| 写法 | 中文写法 | 说明 |
| --- | --- | --- |
| `now()` | 当前时间() | 当前日期与时间，写作 `yyyy-MM-dd HH:mm:ss`。 |
| `today()` | 今天的日期() | 今天的日期，写作 `yyyy-MM-dd`。 |
| `year(date)` | 取年份(日期) | 某个日期的年份。 |
| `month(date)` | 取月份(日期) | 月份，1 到 12。 |
| `day(date)` | 取几号(日期) | 几号，1 到 31。 |
| `hour(date)` | 取小时(日期) | 小时，0 到 23。 |
| `minute(date)` | 取分钟(日期) | 分钟，0 到 59。 |
| `second(date)` | 取秒数(日期) | 秒，0 到 59。 |
| `weekday(date)` | 取星期几(日期) | 星期几，按 ISO 数：1 是星期一，7 是星期日。 |
| `dateAdd(date, amount, unit)` | 日期加减(日期, 增减量, 单位) | 往后或往前挪一段时间；单位是 `seconds`、`minutes`、`hours`、`days`、`weeks`、`months` 或 `years`。 |
| `dateDiff(from, to, unit)` | 日期相差(起始日期, 结束日期, 单位) | 两个日期相差多少个单位。 |
| `formatDate(date, pattern)` | 格式化日期(日期, 正则) | 按 `yyyy/MM/dd` 这样的写法把日期写成文字。 |
| `parseDate(text, pattern)` | 读出日期(日期文字, 正则) | 按同一种写法从文字里读出日期，读出来就能直接交给 `dateAdd`、`dateDiff` 或比较。 |

### 记录

| 写法 | 中文写法 | 说明 |
| --- | --- | --- |
| `jsonGet(json, path)` | 按路径取值(JSON, 路径) | 按 `a.b[0].c` 这样的路径取 JSON 里的一项；取到的如果是对象或列表，交的是它自己的 JSON 文字。 |
| `jsonKeys(json)` | 列出字段名(JSON) | JSON 对象的字段名，按写下来的顺序。 |
| `jsonHas(json, path)` | 路径有没有(JSON, 路径) | 这条路径在 JSON 里有没有。 |
| `jsonSet(json, path, value)` | 按路径改值(JSON, 路径, 要写入的值) | JSON 的一份副本，把这条路径设成某个值，路上缺的字段会补出来。 |
| `jsonOf(name, value, ...)` | 造一条记录(字段名, 要写入的值, ...) | 名字与值轮流写，拼成一个 JSON 对象。 |
| `toJson(value)` | 写成 JSON(值) | 把一个值写成 JSON 文字，列表因此变成数组。 |
| `field(record, name)` | 取字段(记录, 字段名) | 取记录里的一项，比如一次命中的 `x`；名字写错时报错并列出可用的字段名。 |

### 值与选择

| 写法 | 中文写法 | 说明 |
| --- | --- | --- |
| `number(value)` | 转成数字(值) | 把一个值按数字读。 |
| `text(value)` | 转成文字(值) | 把一个值按文字读。 |
| `bool(value)` | 转成真假(值) | 把一个值按真假读。 |
| `if(condition, whenTrue, whenFalse)` | 条件选择(条件, 成立时, 不成立时) | 按条件在两个值里挑一个。 |
