# 手动验收与界面自省

所属：[WhaleGenie 开发说明](../dev.md)。

## 让 agent 自己调试界面（只能 Debug）

`Declarative.Avalonia.AgentTools` 是一个**跑在进程里**的 MCP 检查器：它把正在运行的这一份界面交给
agent，让 agent 自己读、自己点、自己看结果，而不是由人截图转述。它读的是真的那一扇窗，不是无头重绘。
**只在 Debug 编译里存在**：Release 既不还原 `AvaloniaUI.DiagnosticsSupport`，也不会把这个服务开起来
——用 Release 二进制或安装包启动时，`get_app_info` 一定失败；这时先去检查启动的是不是 Debug 版，
不要先怀疑 MCP 配置。

用法就是普通 MCP：按你用的客户端配一个 `avalonia-agent-inspector` 即可——端点、传输方式与各客户端的
配置片段都在包自带的 README 与 `docs/agent-tools.md` 里，这里不重复。程序这边只负责在 Debug 下把服务
开起来。`EnableInteraction` 打开后才有 `tap`/`invoke`/`type` 这一类真驱动界面的工具，只读那一层默认就有。

```bash
# 1. 结束上一次的进程。文件被锁时新编的 exe 不会生效，跑的还是旧进程。
taskkill /IM WhaleGenie.exe /F

# 2. 必须用 Debug 编，并且是 x64：解决方案只提供 x64 平台，
#    Debug 输出在 bin/x64/Debug/<框架>/，不是 bin/Debug/，也不是 bin/x64/Release/。
dotnet build WhaleGenie.slnx -c Debug -p:Platform=x64

# 3. 用后台任务启动它（前台运行会一直占着这次调用，超时被杀，等于没看）
WhaleGenie/bin/x64/Debug/net10.0-windows10.0.19041/WhaleGenie.exe
```

起来之后先调一次 `get_app_info`：连不上就是没开 Debug 版，或者进程已经退出了。

**按要回答的问题选工具**：

| 问题 | 工具 |
|---|---|
| 这扇窗里有什么、焦点在哪、有没有 popup | `get_app_info`（先调它认路） |
| 视觉树长什么样、某个控件在哪 | `get_visual_tree`（带 `abs=`/`center=` 坐标）、`find_text`、`hit_test` |
| 这个控件为什么这么大、为什么看不见 | `get_layout`、`layout_audit`（零尺寸、越界、重叠、文字被裁） |
| 这个值从哪来（本地、样式、模板、动画、继承） | `get_properties`、`get_property_sources` |
| 绑定对不对、DataContext 是什么 | `get_data_context`、`get_errors`（绑定、转换器、事件里的异常） |
| 程序自己打印了什么 | `get_logs`（Avalonia 的 `Logger` 与 stdout/stderr 都在环形缓冲里） |
| 改这一处要动哪个文件 | `get_source`（可带 `file:line`） |
| 版面有没有变慢、掉帧 | `get_render_stats`（fps、布局耗时、视觉数） |
| 看一帧画面 | `screenshot_window`（`maxWidth` 压到 1100 以内够看版式）、`screenshot_region`（`scale=3` 放大看一块）、`compare_screenshots`（前后像素差） |
| 把界面真的驱动一遍 | `tap`/`click_at`/`invoke`/`type`/`key`（`EnableInteraction` 打开后）、`wait_for`/`wait_idle` |

工具是给 agent 自己闭环用的：改一版、驱动一次、读一遍错误和版面，再决定下一步。**截图只是其中一种
读法**，不是这条通道的用途。

**踩过的坑，按发生频率排**：

- **进程必须在后台活着**。这条路连的是"一扇正在跑的窗口"，进程退出就没有可看的东西。在 shell 里用
  `&` 起进程不算后台：调用一返回它就被收走，下一次 `get_app_info` 直接报 POST 失败。用工具自带的
  后台运行起进程；前台跑会一直占着这次调用，超时被杀，等于什么都没看。
- **发的是旧二进制**。调试版的输出在 `bin/x64/Debug/<框架>/`，而 `dotnet build WhaleGenie/WhaleGenie.csproj`
  默认写到 `bin/Debug/<框架>/`——两者不是同一份文件。改完代码要么 `-p:Platform=x64`，要么整解编译；
  启动前先 `taskkill /IM WhaleGenie.exe /F`，否则文件被锁、跑的还是上一次的进程。
- **截图里没有 popup**。下拉、`Flyout`、菜单都是独立的 top-level，`screenshot_window` 只画这一扇窗，
  所以"截图里没看到"不等于"没弹出来"。用 `get_app_info` 的 `Open popups` 计数判断，确实要看图时
  用程序自己的抓屏读那块屏幕。
- **交互是异步的**。点完先 `wait_idle` 或再取一次 `get_app_info`，再截图；窗口列表里窗口消失往往
  就是"按钮按下去、对话框关掉"的证据。
- **`screenshot_window` 的 `windowId`** 写窗口标题（"宏编辑器"、"动作编辑器"）比写序号稳，序号会随
  窗口开合变。

## 手动验收清单

按受影响范围选择项目，并在提交信息中记录 Windows 版本、DPI、显示器数量、相关外部程序版本、
操作步骤和观察结果。环境变化后重新验收受影响项目。

- **输入与取色**：在记事本等现有程序中验证点击、输入、拖选和滚轮；在已知颜色位置验证抓屏取色。
- **界面宏**：给一个宏加界面触发并选目标窗口，把目标窗口切到前台，按钮组应出现在目标客户区内；
  再点别的程序让目标失焦，按钮组应仍留在原窗口内、位置不跳；关闭或最小化目标后按钮组消失，
  恢复后再出现。不选窗口的规则跟随前台窗口移动。把另一个窗口拖到目标窗口上方，按钮组应被一起盖住，
  不能透过焦点窗口显示。点把手上的折叠按钮，按钮收起、只剩顶部约 20 像素的窄条；在窄条下面点一下，
  应直接点到下面的窗口（不是点到面板）。再点窄条上的展开按钮恢复；点排列按钮，按钮在
  竖排与横排之间切换，横排变宽后仍应落在目标客户区内。拖动一次按钮组，位置按目标客户区保存。
- **五类拾取器**：框选、取色、点、元素和窗口规则分别进入与退出，检查焦点、Esc、回车、右键、
  鲸灵窗口隐藏与恢复；在添加动作窗口中至少验证一次。
- **识别画面上的拾取**（`LookPickWindow`）：点击图片 / 点击文字 / 点击检测到的物体的「拾取点位…」，
  以及多点找色的「拾取偏移与颜色…」。要验的是偏移以命中中心为原点、点在框外仍然有效、
  颜色取自打开那一刻的识别画面（不是此刻的屏幕），以及这一步没找到东西时给出说明而不是空窗。
  多点找色还要验：表单上不再有「周围要对的颜色」一格；「对比色（N 处）」一节（标题、序号/偏移/
  颜色/色块那一列与拾取按钮）在**容差之后**，拾完后这一列随即更新；拾取器打开时带出已有
  那几处，确定后整张表写回、取消不改；圆点与列表上的序号对得上；拖圆点改一条、右键圆点出菜单、
  空白右键不多条、滚轮键单击新增；左上的「+」与每行「编辑…」都开得出一行三框、框末带表达式的窗口。
- **定格与框选**：取色后移动背景窗口或播放视频，确认读数仍来自打开时的画面；框选图不得包含鲸灵窗口。
- **FluentAvalonia 窗口**：在深色和浅色主题下检查标题栏、窗口控制按钮、扩展标题栏拖动、文本对比度和
  关键控件布局。
- **设置窗口的十个页面**：深色与浅色各走一遍「通用、快捷键与声音、屏幕捕获、输入、设备与权限、菜单、
  窗口规则、轮盘菜单、轮盘动作管理、主题」，检查顶部分组切换与左列是否同步、切组是否落到该组第一页、卡片左右两端
  是否对齐、每张卡片的开关与数字框是否落在同一列，以及说明是否换行而不是被截断；再把窗口拉到最小
  尺寸（780×560）看一遍，确认右侧控件没有被挤压、只有内容区出现滚动条。输入页现在只有两项
  （输入限制与忽略自己的输入），点输入限制旁的 info 图标应弹出整段说明、能选中复制、换行不挤在一起。
  只有一项的卡片不再重复字段
  标签，确认卡片头自己说清了这一项、说明贴着卡片头显示。打开窗口本身不应改写 `settings.json`。
- **轮盘菜单**：先启用系统总开关（`Home`）。中键按下应照旧弹出菜单宏；**短按右键**应照旧
  弹出系统右键菜单，鲸灵不出任何界面；**按住右键并移动**才弹出轮盘，且以按下点为中心。移向内圈、
  外圈时扇区高亮并有一根从中心到指针的实线；划到圆盘之外，线变成虚线并伸出可见圆盘、末端跟着
  指针，中心只显示该方向动作的**宏名字或备注**（没有「划一下」之类的提示词）。快速移动指针时
  线的末端应始终贴着指针，不能落后一截。中心圆显示「关闭」，在中心松开、`Esc`、
  左键都取消；**取消之后立刻点几下左键，确认没有被吞掉**（这是曾经因为只拦截松开而出现的回归）。
  悬停按 `F1` 重复触发；超时自动取消。在屏幕边缘触发确认可见轮盘仍在屏幕内。设置页点「预览轮盘」
  应能在不经过全局钩子的情况下打开窗口、悬停高亮、松开显示「将运行：…」，`Esc` 关闭。把触发键
  改成中键 / 4 侧键各验一次，再关掉「启用轮盘菜单」确认右键完全不受影响。第三圈容量切到
  8/16/24 各看一次版面与命中；只给内圈填动作时确认空外圈被隐藏。在动作管理页右键一个扇区，
  确认「编辑轮盘动作」能改宏、备注与图标，选一个图标后文字上方出现它；「清除该位置」把整格清空。
  新增一个按进程名匹配的程序场景、覆盖一个位置，确认其余位置显示「（全局）」；轮盘弹出后滚动滚轮三次，确认
  来源按叠加／全局／当前程序／叠加变化。把重复键从 `F1` 改成 `F8` 验一次，再关掉光泽、
  悬浮边框、弹出动效与主题跟随，确认浅色固定盘面仍可读。
- **屏幕捕获设置**：把「跟随屏幕刷新率」关掉，确认数字框可改、上限等于设置页显示的赫兹数；填一个
  比刷新率大的值，确认保存后回到上限。打开「复用上次的画面」，确认保留时长那一格跟着可用；
  跑一个连续识别同一窗口的宏，比较开关前后的运行耗时。
- **存储位置打不开**：把某一行的目录设为只读后点「打开」，确认界面只出现一句「文件夹打不开，
  详情见日志」，`runtime.log` 里有这一次的异常，窗口里不出现 .NET 原文。
- **驱动级输入**：安装 usbip-win2，分别验证启动时加载与否、键鼠动作和手柄；退出后确认虚拟设备已移除。
- **识别与录制**：验证 YOLO 检测、等待与点击落点；验证录制热键、动作翻译和停止流程。
- **脚本与依赖**：验证批处理、PowerShell、Python、C#、AutoHotkey、包安装及断网失败路径。
- **编辑器交互**：验证表达式拖放、动作落点、取消与保存、公共宏版本复制及重启后的公共宏库。
  宏设置的两页都要在 360 像素宽的右栏里走一遍：`常规` 与 `专属设置` 来回切、滚动只发生在当前页、
  标题与按钮不动；专属页填一个每宏限速（含 0）并跑一次，确认打字与点击按这个速率发出；录一个
  启用/停用键，回到主界面按它两次，确认宏先停后开、这个键本身没有打进前台窗口，再在没有保存的
  情况下关掉编辑器，确认恢复提示还在。
- **取值窗口**：在条件或表达式格打开取值窗口，格里的裸名字不应被判成「读不通」，「确认」可用；小输入框
  里 `1e5`、`1,000`、`+5` 被拒，`3.5`、`-5` 可插入；点过结构带后直接敲字母，字符应落进小输入框；在小
  输入框里按 Ctrl+Z 只撤输入框里的字，公式不动；把一块拖到会让可读式子读不通的位置，松手不应执行，落点
  线也不画；把整条公式清空后「确认」应把这一格清空；输入一个没有声明的名字，块上应描红边；用中文输入法
  在小输入框里打一段文字，确认候选窗与回车不冲突。
- **变量名字与格式 32**：打开一个 31 及更早的 `.wgmacro`，确认被拒绝并给出可读的版本提示；新建一个宏，
  加全局变量、局部变量和一个「设置变量」步骤，保存后重新打开，确认引用仍读到同一个值；把全局变量改名，
  确认同名局部变量没有被跟着改；从取值窗口选一个名字写进条件行，保存再打开，确认仍按名字读取，且文件里没有 `$` 前缀。
- **两个工程各一张表**：打开 `A`，在变量中心加一个全局变量并让一次运行写入值；不关程序直接打开 `B`，
  确认变量中心里没有 `A` 的声明，`B` 里声明同名变量也读不到 `A` 的值；回到 `A` 那份包重新打开，确认值
  只按持久化规则恢复。
- **变量约束与生命周期**：声明一个数字局部变量，用「设置变量」写一段文字，确认那一步失败并报
  `Run.VariableTypeMismatch`；声明一个叫 `i` 的局部变量再加一个 `for i` 循环，确认检查器标红且不能运行；
  用「清除变量」清掉一个只在步骤里写过的局部变量，确认之后再读它报未定义；清掉声明过的局部变量，确认它回到
  该类型的空值；清掉一个全局变量，确认回到声明初值；跑一个
  每轮写新名字的循环，确认日志只提醒一次变量表变大，值没有丢。
- **日期类型**：把一个全局变量声明为 `date`，默认值写 `2026-11-13`，保存后确认预览不带时间；在条件里用取值窗口搭出 `日期 < today()`，确认按时间比较而不是按字面；把 `sort([today(), parseDate("2020-01-01", "yyyy-MM-dd")])`
  放进一个值格里，确认第一项是 2020-01-01；勾上持久化，重启后确认它仍是日期（预览不变成一长串文本）。
- **类型词汇与包 31**：保存一个带整数、文本、布尔、日期、图片结果的宏，用文本编辑器打开 `.wgmacro`，确认
  `type` 写成 `Number` / `Text` / `Bool` / `Date` / `Image`；打开一个 30 的包，确认被拒并给出 31 的提示；
  在变量中心的下拉里确认没有「颜色」，日期与图片可选。
- **声明默认值形状化**：在宏接口里给一个参数用取值窗口写入 `数量 + 1`（引用 + 算式），保存再打开，确认
  仍是同一形状、文件里 `default` 是带 `op` 的对象而不是一行带 `$` 的字；在局部变量管理器里用取值窗口给
  初值写入一段夹着变量名的文字，保存往返后确认名字仍是名字、文字仍是文字；两个输入框都只读，唯一入口是
  「取值」按钮；`whalegenie_get_macro_signature` 的 `defaultShape` 与文件里的形状一致。
- **等号与文本**：在条件里写 `1 == "1.0"`、`today() == 今天`（用日期字面量），确认都成立；写
  `"1" == "1.0"`，确认不成立；把 `unique([1, "1", "1.0"])` 放进值格里，确认只剩一项。
- **日期字面量**：在值格里写 `2026-11-12`，确认得到日期而不是 2003；写 `2026-11`，确认仍是 2015；
  写 `2026-11-12.csv`，确认不被当成日期。
- **循环绑定**：声明一个局部 `i` 初值 7，再写一个计数器为 `i` 的循环体，运行后确认 `i` 回到 7；在循环内
  读 `sys.loopIndex` 正常，在循环外读它，确认那一步报 `Run.BadExpression`。
- **压缩包的两个层次**：打一个含文件的 `photos` 目录，两种设置各打一次并解压：不带上得到里面的文件，
  带上得到 `photos/` 目录；对同一个目标再打第二次，确认替换而不是失败。
- **透明色与不同底色**：同一张小图标分别放在两种底色上截两次图，用其中一张当参考图、填上它那一种底色
  作透明色，确认在另一张上仍找得到；把透明色清空，确认行为与从前一致。
- **元素锚点与两个同名按钮**：在一个界面上放两个同名按钮，用「在某个元素右边」把这一步钉到其中一个；
  再删掉锚点元素所在的控件，确认这一步按没找到处理，而不是落到另一个同名按钮上。
- **注册表与环境变量**：在当前用户下写一个值再用 `regedit` 看到、读回；写 HKLM 未确认时被拦下并说明原因；
  写一个用户变量后新开一个 `cmd` 读到它，并确认已经开着的 `cmd` 读不到。
- **其他发布资源**：涉及收款码变更时，分别用手机扫码验证内容。

真实输入须在交互式 Windows 会话中验证。不要通过落入会话 0 的 SSH 会话判断桌面输入或窗口行为。
