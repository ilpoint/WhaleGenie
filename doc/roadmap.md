# WhaleGenie 开发路线图

本文件只记录尚未完成的工作、待评估事项和产品非目标。长期规范见
[AGENTS.md](../AGENTS.md)，开发与验收命令见 [dev.md](dev.md)，当前实现见
[architecture.md](architecture.md)，已实现的用户行为见 [manual.md](manual.md)。

## 规划规则

- 阶段完成后删除对应内容，变更历史由 git 保存。
- 一个阶段只解决一类问题，并具有明确的依赖、修改范围、自动化验收和必要的手动验收。
- 不记录工期。优先级依次考虑：用户能否表达需求、文档与实现是否一致、多条宏同时运行是否正确。
- 先处理契约和静默错误，再处理行为扩展与操作便利；游戏与办公场景具有同等优先级。
- 待评估事项必须先取得测量结果，再决定是否升级为阶段。

## 当前阶段：设置项收口

### 目标

将需要用户调整的分散行为集中到现有设置窗口，不新增设置根页面。设置归入：

- **常规**：启动时加载上次项目、启动时启用系统、已启用宏排前、退出时自动保存、默认图片目录、
  日志保留份数、以管理员身份运行。
- **输入与捕获**：输入限制、独占输入、忽略自身输入。
- **快捷键**：录制热键及既有声音开关。

### 已确定的行为

| 设置 | 行为约定 |
| --- | --- |
| 输入限制 | 单位为每秒键盘或鼠标事件数，范围 0～999，默认 120 且默认启用；0 表示关闭。打字、按键、点击、滚轮和拖拽事件计入，组合键计一次，鼠标移动不计入。该值是上限而非目标速率 |
| 独占输入 | 改为全局设置，默认关闭。删除 `MacroItem.ExclusiveInput`、编辑器对应区域及 MCP 的 `exclusiveInput` 字段。仅发送键鼠的步骤参与排队，读取屏幕、识别和等待不排队 |
| 忽略自身输入 | 使用一处全局开关，默认开启，同时控制触发器判定和新建录制器的初始值；录制面板保留本次录制的临时覆盖 |
| 日志保留 | 默认保留 100 份，可输入数量。启动时清理 `logs/` 下按日期或运行生成的 MCP 与失败日志，按修改时间删除最旧项；`runtime.log` 继续由自身滚动机制管理 |
| 默认图片目录 | 系统图片文件夹下的 `WhaleGenie` 子目录。仅影响项目尚未保存时由宏生成的图片；已保存项目仍使用包对应的 `X.assets/`。该目录与开发评审截图使用的 `%temp%\WhaleGenie` 无关 |
| 退出时自动保存 | 默认开启。隐藏窗口不算退出；真正退出时只保存已有路径且已修改的项目，不为新项目自动选择路径，保存失败须明确报告 |
| 以管理员身份运行 | 清单保持 `asInvoker`。设置开启且当前未提权时，通过 `--elevated` 请求提权重启；UAC 被拒绝后本次不再重复询问 |
| 宏启用入口 | 在宏列表右键菜单提供启用与停用，保留现有状态显示和 MCP 能力 |
| 声音 | 整理既有声音开关，不增加宏结束或失败时自动播放声音的全局机制；需要声音时在宏中使用 `system.sound`，不支持自定义音频文件 |

独占输入全局化不升级包格式版本：加载器不再读取该字段，既有包中的该字段按未知字段忽略，
不增加兼容读法或迁移分支。

### 实施阶段

阶段 1 是后续设置项的共同前置。其余阶段按依赖实施；涉及模型或 MCP 契约的修改独立验收，
不与无关界面整理混合。

| # | 阶段 | 主要修改与验收重点 |
| --- | --- | --- |
| 1 | 设置骨架与启动行为 | 增加 `LocalSettings` 字段和三个启动设置；验证设置持久化、上次项目加载条件、系统启用初值及已启用宏稳定排序 |
| 2 | 输入限制 | 在 Core 增加输入节流包装，统一限制键盘与鼠标事件；验证事件间隔、组合键计数、鼠标移动不受影响及 0 表示关闭 |
| 3 | 独占输入全局化 | 删除宏级字段、编辑器区域和 MCP 契约，由运行装配读取全局设置；验证输入门顺序、子宏行为、包读写和 MCP 拒绝旧字段的提示 |
| 4 | 忽略自身输入 | 连接触发器与录制器初值；验证全局默认值和单次录制覆盖互不污染 |
| 5 | 宏启用入口 | 增加宏列表右键启用与停用；验证状态、排序、触发器和 MCP 读取结果一致 |
| 6 | 声音设置归位 | 将既有声音开关集中到快捷键页；验证设置保存和既有 `system.sound` 行为不变 |
| 7 | 退出时自动保存 | 接入统一退出流程；验证有路径且已修改才写入、无路径不写、保存失败可见、隐藏窗口不触发保存 |
| 8 | 默认图片目录 | 调整未保存项目的图片路径选择；验证已保存项目路径不变、目录可创建及写入失败可诊断 |
| 9 | 日志保留 | 增加启动时日志清理；验证只处理目标文件、按修改时间保留指定份数且不删除 `runtime.log` |
| 10 | 录制热键 | 由应用层读取设置，并通过构造参数、录制选项或设备契约注入 `InputHookRecorder.StopKey`；Core 不读取界面设置。验证持久化、界面文案和真实录制停止 |
| 11 | 以管理员身份运行 | 在 `Program` 增加提权判定和重启分支；覆盖已提权、未开启、UAC 接受和 UAC 拒绝四种情况 |

### 整体验收

- 设置保存、加载和缺省值有自动化用例，设置页面不新增根页签。
- 输入限制、输入门、宏启用、自动保存、图片目录和日志清理均有边界用例。
- MCP 工具描述、允许字段和补丁校验不再暴露 `exclusiveInput`。
- 手册按设置页面列出各项，说明单位、范围、默认值和生效时机；开发文档只保留实际操作入口。
- 手动验证真实录制热键、输入限制开启后的真实程序行为及 UAC 提权流程。
- 完成后运行构建、全部测试和格式检查，并从本文件删除本阶段。

## 待评估

以下事项尚未承诺实施。升级为阶段前须写明测量结果、目标、范围和验收方法。

### 契约与正确性

- **试运行的执行路径对账**：`LooksAtScreen` 已由目录声明，但 `SeeOnce` 等实际查看路径仍含手写分派。
  先统计声明与实现可系统性漏配的动作，再决定采用目录驱动、按动作键对账或反向 fixture。
- **其余等待动作的行为用例**：部分等待动作只验证能够结束。参照已有的“第 N 次才满足”夹具，
  优先覆盖 `vision.waitColor`、`browser.waitFor*` 和 `clipboard.waitChange`，确认等待、满足和超时
  三种路径。
- **补丁成本**：当前局部补丁仍需读取并校验整宏。使用约两百步的宏比较 `set` 与 `get_step` 的耗时，
  确认瓶颈后再决定是否引入增量校验。

### 结构与诊断

- **审计与失败日志的读取边界**：两类日志同处 `logs/` 但文件名不同。检查一次真实运行产生的文件及
  读取路径，决定是否需要目录分离或显式路径参数。
- **无界面命令行**：只有出现 CI 批量验包、脚本生成宏等真实调用方时，才评估将 `Models/`、
  `Storage/`、`Localization/` 拆出界面工程；没有调用方则不新增入口。
- **MCP 工具发现与审计登记**：工具类型和审计调用仍有手工登记点。先通过故障注入确认漏登记能否被
  现有测试发现，再决定是否采用自动发现或统一拦截。

### 动作与编辑器表达

- **询问与说明的重复入口**：评估 `control.ask` 与 `control.input`、`control.note` 与步骤备注的
  实际使用差异，再决定合并或保留。
- **变量写入动作数量**：评估 `setVariable`、全局累计和列表写入动作在动作库中的搜索与选择成本，
  不仅为减少动作数量而合并。
- **子宏入口**：评估子宏 Dock 的导航与插入用途；只有页面导航已有等价入口且使用数据支持时才移除。

## 产品非目标与暂不计划

以下事项不属于当前产品方向。重新提出时须说明前提变化、真实使用场景和可验收收益。

- **防检测与隐藏**：不读取其他程序内存、不修改其程序包，不提供驱动级隐藏。VIIPER 仅作为输入通道。
- **专用验证靶场**：不在产品或测试中恢复只验证自身的靶场窗口；真实输入使用现有桌面程序验收。
- **多尺度模板匹配**：分辨率变化时使用相应参考图，不引入自动多尺度匹配。
- **办公文档与企业系统解析**：不内置 PDF、Word、工作簿或企业系统连接器；数据文件聚焦 CSV、JSON
  和纯文本。通用 HTTP、数据库和邮件动作也需有反复出现的真实流程后再评估。
- **第二套流程机制**：不引入宏内并行块、从块内失败点继续或替代块结构的流程系统；并发由多个宏表达。
- **浏览器多实例**：同一时刻保持一份浏览器，通过标签页和浏览器门管理操作。
- **额外记录访问语法**：不增加 `x(记录)`、`y(记录)`、`point(记录)` 或 UIA 运行时句柄持久化；
  使用现有 `field()`、位置/矩形字段和稳定窗口规则。
- **完整静态类型系统**：只进行目录声明支持的类型检查，不做类型推导。
- **物理单位与 DPI 换算**：坐标与尺寸统一使用屏幕像素。
- **自动记住动作表单输入**：重新打开动作时使用默认值；需要复用时复制步骤。
