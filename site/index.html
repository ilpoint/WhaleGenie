WhaleGenie 鲸灵 把重复操作，写成一条宏。

WhaleGenie（鲸灵）是 Windows 上的宏与自动化工具。键盘、鼠标、手柄、屏幕与窗口上的操作， 可以按顺序编成一条宏，由热键或事件触发。 游戏与办公同样适用，不需要写代码。

下载 Windows 版 查看源码 ↗

操作被拆成动作，动作排成一条宏。

从动作库中选取要执行的步骤，按顺序排好，再设置触发条件。运行、暂停与调试都在同一个窗口里。

输入与触发

键盘按键，鼠标按键、移动与滚轮，手柄按键与摇杆；前台、后台消息与驱动级虚拟 USB 三种输入方式。一个宏可以绑定多个入口。

画面识别

找图、找色、多点找色、画面静止、屏幕取字与取色；内置 YOLO 检测，识别到目标后可以直接点击图片或文字。

窗口与元素

按标题、进程名或类名定位窗口，移动、缩放、置顶、显示或隐藏；通过 UI Automation 读取和操作控件。

浏览器

打开页面、点击元素、填写表单、读取文字与属性、截图、切换或关闭标签页；默认使用系统自带的 Edge。

文件与数据

读写文本、CSV 与 JSON，使用剪贴板（含图片），操作文件夹与进程，执行命令行或脚本。

流程与调试

循环、分支、尝试与收尾、子宏调用；断点、单步、识别结果、步骤状态与运行日志帮助定位问题。

录制键鼠操作可以直接生成步骤；图片、窗口、元素、颜色、区域、按键、手柄与变量各有拾取器。 宏以 .wgmacro 保存，连同参考图一起打包；未保存的内容留有崩溃恢复快照。

三层界面，各司其职。

主界面选择并启停宏，宏编辑器按执行顺序编排步骤，动作编辑器只修改选中的那一步。

01

主界面

宏按用途分页，搜索只筛选当前页；每张卡片可以直接启停、编辑或删除。

02

宏编辑器

左侧取动作，中间排步骤，右侧管理变量与设置；循环与分支显示为可折叠的块。

03

动作编辑器

只编辑选中的步骤，参数按页分组；子步骤回到宏编辑器里组织和排序。

开始使用。

下载、解压、运行，三步即可；也可以从源码构建，构建与验收命令写在开发文档里。

下载即用

从 Releases 下载压缩包，解压后运行最外层的 WhaleGenie.exe。自带运行时的包不依赖预装环境。

$ WhaleGenie-<版本>-win-x64-standalone.zip ↗

从源码构建

仓库使用 .NET 10 与 Avalonia，执行引擎与界面分离；构建、测试与打包命令写在开发文档里。

$ git clone https://github.com/ilpoint/WhaleGenie ↗

需要 Windows 10 2004（内部版本 19041）或 Windows 11，64 位。界面支持中文与英文，首次启动跟随 Windows 显示语言。
